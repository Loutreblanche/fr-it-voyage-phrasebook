# FR-IT Voyage — Phrasebook

Répertoire de phrases et de vocabulaire pour voyager entre la France et l'Italie, sous forme de PWA installable et utilisable hors-ligne.

## Installer sur le téléphone

1. Ouvrir l'appli dans le navigateur du téléphone (Chrome sur Android, Safari sur iPhone).
2. **Android (Chrome)** : menu ⋮ → « Ajouter à l'écran d'accueil ».
3. **iPhone (Safari)** : bouton Partager → « Sur l'écran d'accueil ».
4. Ouvrir l'appli une première fois connecté, puis elle fonctionne hors-ligne.

## Développement local

```bash
python -m http.server 8080
```

Puis ouvrir `http://localhost:8080`.

Avant chaque livraison, lancer la validation automatique :

```bash
node validate.js
```
